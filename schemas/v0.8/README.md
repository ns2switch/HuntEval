# HuntEval schema 0.8

Schema 0.8 adds immutable controlled-improvement contracts. It is additive: schema 0.3 through 0.7 artifacts remain unchanged and retain their existing readers.

The contracts cover content-addressed artifact registration, explicit structured sections, safe diffs, immutable improvement policy, paired experiments, equivalence and validation decisions, append-only recommendation lifecycle, explicit human decisions, externally confirmed adoption, prompt/configuration weakness taxonomy, normalized reports, and offline-verifiable bundles.

These schemas define data boundaries only. They do not claim that R6 registry, diff, orchestration, lifecycle, prompt-analysis, report, verification, or CLI services are implemented. Unknown versions, fields, variants, states, references, policies, and applicability values fail closed. Candidate generation never receives hidden-test membership or feedback, and no schema authorizes automatic modification or adoption of a deployment artifact.
