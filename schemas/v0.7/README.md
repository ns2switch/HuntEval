# HuntEval schema 0.7

Schema 0.7 adds immutable evidence-backed diagnosis contracts. It is additive: schema 0.3 through 0.6 artifacts remain unchanged and retain their existing readers.

The contracts cover a reviewable diagnostic taxonomy, exact observable-source references, failure classifications, per-run diagnosis, recurrence grouping, runner-authoritative bottleneck observations, bottleneck metrics, controlled topology-dependent contribution, normalized diagnostic reports, and content-addressed bundle manifests.

These schemas define data boundaries only. They do not claim that R5 classifiers, reducers, report writers, verification services, or CLI commands are implemented. Unknown versions, variants, fields, references, applicability states, and confidence levels must fail closed in their owning implementation milestones.
