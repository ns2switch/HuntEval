# Roadmap

## v0.1 — Experimental runner

- single-agent reference deployment;
- DuckDB and Parquet execution;
- basic event and entity evaluation;
- CLI;
- trajectory recording.

## v0.2 — Multi-agent protocol

- deployment registration;
- agent identities and capabilities;
- task and message events;
- evidence provenance;
- three baseline topologies.

## v0.3 — Cloud benchmark

- AWS, Azure, and Google Cloud;
- nine synthetic episodes;
- benchmark manifests;
- scoring profiles;
- repeated-run ranking.

## v0.4 — Coordination and resilience

- coordination metrics;
- fault injection;
- graceful degradation;
- task reassignment;
- bottleneck analysis.

## v0.5 — Diagnosis

- failure taxonomy;
- rule-based classifiers;
- agent attribution;
- evidence-backed prompt recommendations;
- comparative reports.

## v0.6 — Prompt experiments

- prompt artifact registry;
- A/B testing;
- train, validation, and hidden-test partitions;
- regression detection;
- immutable safety sections.

## v0.7 — Auxiliary RAG

- retrieval over hunt-author knowledge;
- indexing of reports and historical runs;
- artifact-grounded questions and answers;
- citations to run and document IDs.

## v0.8 — Extensibility

- Python SDK;
- tool-plugin interface;
- external deployment adapters;
- dataset contribution tooling;
- compatibility test suite.

## v1.0 — Stable platform

- stable protocol and schemas;
- reproducibility and security audit;
- official cloud benchmark pack;
- documented governance and release process;
- mature CLI and static reporting;
- validated prompt-diagnosis workflow.

## Post-1.0 candidates

- adapters for production SIEM query languages in non-scored or controlled modes;
- distributed benchmark execution;
- public leaderboards with signed artifacts;
- automated prompt candidate generation under strict constraints;
- richer causal and graph-based attribution;
- multimodal investigation artifacts.
